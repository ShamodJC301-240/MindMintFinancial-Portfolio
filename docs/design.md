# Design System — The Mint

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--mint` | `#2D7A4F` | Primary brand, buttons, links |
| `--mint-light` | `#3CA066` | Hover states, pulse dots |
| `--mint-pale` | `#E8F5EE` | Card backgrounds, tags |
| `--mint-mist` | `#C8E8D4` | Borders, dividers |
| `--forest` | `#1A4D32` | Dark variant, gradients |
| `--gold` | `#C8A84B` | Logo accent, premium card |
| `--text` | `#1C2B22` | Body text |
| `--text-muted` | `#5A7A66` | Secondary text, labels |

## Typography

- **Display / Headings:** Playfair Display (Google Fonts) — weights 400, 700, 900
- **Body / UI:** DM Sans (Google Fonts) — weights 300, 400, 500, 600
- Base font size: 16px
- Line height: 1.6 (body), 1.1 (headings)

## Spacing Scale

`4px · 8px · 12px · 16px · 20px · 24px · 32px · 40px · 48px · 64px · 80px · 100px`

## Border Radius

- Cards: `20px`
- Buttons: `50px` (pill)
- Tags/badges: `50px`
- Inputs: `12px`
- Icons: `14px`

## Shadows

- Card default: `0 4px 20px rgba(26,77,50,0.06)`
- Card hover: `0 16px 48px rgba(45,122,79,0.12)`
- Modal: `0 32px 80px rgba(26,77,50,0.2)`
- Balance widget: `0 8px 32px rgba(26,77,50,0.12)`

## Components

See `css/components.css` for all reusable component styles.

Key components: `.btn`, `.card`, `.modal`, `.field`, `.badge`, `.tab`, `.txn`, `.progress-bar`
